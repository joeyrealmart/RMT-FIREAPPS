# RMT Reporting

- Build reports from authoritative shared inspection, SOP, evidence, sign-off, linked-verification, and audit records.
- Keep customer summary presentation separate from internal detailed audit history.
- Preserve source record IDs, technician identities, timestamps, revisions, evidence references, and approval state.
- Submission must be server-validated and read-only for technicians until Admin returns/reopens it.
- Never fabricate missing results, procedures, signatures, or counts.
- Keep report layout changes separate from inspection and scheduling logic.
