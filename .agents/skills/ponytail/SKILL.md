# Ponytail Context Practice

Use a short task brief first, then disclose only the references needed for the current decision.

1. State objective, allowed files, protected areas, and stop condition.
2. Link to focused repository docs instead of copying full project history.
3. Load detailed implementation context only when the task reaches that area.
4. Keep delegated work isolated and review outputs before integration.
5. Summarize durable findings in project docs so later agents do not repeat discovery.
