## Routing Policy

- Local Ollama: summaries, inventories, static QA analysis, bounded workflow review.
- Deterministic tools: bulk extraction, rendering, graph generation, checksums, parsers, and repeatable QA.
- Codex: production architecture, engine defects, integration, concurrency, migrations, security, and final release review.
- Qodo: independent post-implementation review only; findings are triaged before genuine unresolved issues return to Codex.
- No paid provider or cloud model was used for this tooling and LTK package.
