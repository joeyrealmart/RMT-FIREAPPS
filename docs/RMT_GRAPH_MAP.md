## Dependency Direction

```text
HTML/CSS -> app.js UI/state -> local API -> shared job/schedule/evidence files
                         \-> runtime mimic background + separate device/pin data

QA/UX/Mimic tools -> isolated fixtures/artifacts -> human/deterministic review
                  X production writes unless explicitly approved

Implementation worker -> Qodo independent review gate (`LOGIN_REQUIRED`)
                      -> deterministic QA -> physical test / Joey approval
```

## Update Policy

After meaningful architecture or code changes, run `.tools/graphify/Scripts/graphify.exe update .`, then refresh this compact map. `graphify-out/` is a generated local index and should not be committed wholesale when noisy or large.
