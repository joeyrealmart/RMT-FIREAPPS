# Fire Alarm Control Panel Checklist

Use this checklist for fire alarm panel servicing and testing.

## A. Panel Information

- Panel type: Addressable / Semi-addressable / Conventional
- Brand
- Model
- Panel location
- Total zones / loops
- Zones currently used
- Spare zones available
- Battery quantity and rating
- Charger rating
- Last service date
- Last alarm / fault history if available

## B. Safety Preparation Before Testing

- Inform Facilities Manager / client representative before testing.
- Confirm testing time and affected areas.
- Set panel to silence / alarm test mode before checking devices.
- Switch off / isolate all tripping outputs before testing.
- Confirm lift, air-con, roller shutter, smoke spill fan, pressurizing fan, and gas release interfaces before alarm-mode testing.
- Confirm whether Bomba link / monitoring line needs to be isolated.
- Record who approved the test.

## G. Final Restoration

- Reinstate all tripping outputs / isolations.
- Reset fire alarm panel.
- Confirm panel returns to normal status.
- Confirm no active fault / isolate / alarm left behind.
- Confirm mimic panel normal.
- Inform Facilities Manager / client representative testing completed.
- Record final panel status photo.

## H. Required Photos
