# Sprinkler System Checklist

Use this checklist for sprinkler system servicing, pump testing, alarm valve testing, and zone valve inspection.

## A. System Information

- System location
- Sprinkler tank location
- Pump room location
- Duty pump brand / model
- Duty pump serial number
- Standby pump brand / model
- Standby pump serial number
- Jockey pump brand / model
- Jockey pump serial number
- Pump starter panel brand / model
- Sprinkler alarm valve quantity
- Zone valve quantity
- Flow switch quantity
- Last service date

## B. Safety Preparation Before Testing

- Inform Facilities Manager / client representative before testing.
- Confirm test discharge / drain location.
- Confirm water supply is available.
- Confirm pump power supply is safe before testing.
- For 3-phase supply, measure all phases before testing.
- Confirm standby diesel pump area is ventilated before test run.
- Confirm sprinkler alarm / fire alarm interface before flow proving test.
- Record who approved the test.

## L. Final Restoration

- Return all valves to correct normal open/closed position.
- Return pump panel selector to correct normal position.
- Confirm jockey / duty / standby pump status normal.
- Confirm alarm valves reset and normal.
- Confirm no leakage after testing.
- Confirm fire alarm panel status normal if interface was tested.
- Inform Facilities Manager / client representative testing completed.
