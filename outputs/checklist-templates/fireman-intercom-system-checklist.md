# Fireman Intercom System Checklist

Use this checklist for fireman intercom master panel and slave handset communication testing.

## A. System Information

- System location
- Master panel location
- Master intercom brand / model
- CPU / controller brand / model if available
- Total master quantity
- Total slave handset quantity
- Last service date

## B. Safety Preparation Before Testing

- Inform Facilities Manager / client representative before testing.
- Confirm testing time and affected areas.
- Confirm master panel can be tested.
- Confirm access to slave handset locations.
- Record who approved the test.

## G. Final Restoration

- Confirm master panel returns to normal status.
- Confirm no fault indication left after testing.
- Confirm all handset cabinets are closed and secured.
- Inform Facilities Manager / client representative testing completed.

## H. Required Photos

- Master intercom panel
- Panel normal status
- Battery and charger
- CPU / controller if visible
- Sample slave handset
- Failed handset / damaged glass / damaged lock
- Final normal panel status

## I. Report Remarks

- Master panel issue
- CPU / control operation issue
- No speech master to slave
- No speech slave to master
- Audio unclear
- Broken glass
- Lock damaged / missing key
- Handset damaged
- Parts recommended
- Follow-up quotation required: Yes / No
