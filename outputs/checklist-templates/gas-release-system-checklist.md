# Gas Release System Checklist

Use this checklist for gas release agent panel servicing and simulated discharge testing.

Important: this checklist involves discharge control circuits. Follow site safety procedure and only perform with authorized personnel.

## A. System Information

- Protected area
- Gas release agent type
- Gas release agent panel location
- Panel brand / model
- Cylinder quantity
- Cylinder serial numbers
- Manual release location
- Abort switch location
- Sounder / beacon / flashing light location
- Last service date

## B. Safety Preparation Before Testing

- Inform Facilities Manager / client representative before testing.
- Confirm testing approval before isolating discharge.
- Confirm protected area is safe to test.
- Confirm gas discharge must not occur during test.
- Isolate gas discharge switch.
- Remove discharge cable.
- Do not short circuit discharge cable.
- Remove pyrocharge / solenoid head.
- Record who approved the test.

- Battery / charger issue
- CPU / control issue
