# Portable Fire Extinguisher Checklist

Use this checklist for portable fire extinguisher inspection, Bomba expiry tracking, and barcode/QR data capture.

## A. System Information

- Site / area
- Total extinguisher quantity
- Total 9kg D/P quantity
- Total 2.2kg CO2 / 2kg CO2 quantity
- Last inspection date
- Fire certificate status: N/A / Yes / No
- If fire certificate is yes, expiry date

## H. Required Photos

- Overall extinguisher location photo
- Bomba QR / barcode sticker
- Pressure gauge
- Safety pin / seal
- Nozzle / hose
- Physical damage if any
- Leakage if any
- Expired certificate / expired sticker if any
- Missing location photo if extinguisher is not found

## I. Report Remarks

- Missing extinguisher
- Wrong location
- Expired Bomba certificate
- Drop in pressure
- Empty cylinder
- Safety pin missing
- Physical damage / leakage / clogged nozzle
- Over 10 / 12 years
- Replacement recommended
- Follow-up quotation required: Yes / No
