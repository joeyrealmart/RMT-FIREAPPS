# Tripping System Checklist

Use this checklist for fire alarm tripping/interface testing such as fan, roller shutter, lift, smoke spill, pressurizing fan, air-con shutdown, and other relay-controlled systems.

## A. System Information

- Site / area
- Tripping system type
- Starter panel location
- Connected equipment, for example fan / roller shutter / lift / air-con / smoke spill / pressurizing fan
- Main fire alarm control panel location
- Relay panel location if separate
- Last service date

## B. Safety Preparation Before Testing

- Inform Facilities Manager / client representative before testing.
- Confirm which equipment will activate.
- Confirm testing will not affect occupied / unsafe areas.
- Confirm roller shutter path is clear.
- Confirm fan / motor area is safe.
- Confirm lift / air-con interface test permission if applicable.
- Record who approved the test.

## I. Report Remarks

- Starter panel issue
- Equipment failed to activate
- Slow activation
