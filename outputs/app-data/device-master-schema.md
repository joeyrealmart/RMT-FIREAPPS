# Device Master Schema

This is the backbone table for the maintenance app. Every asset/device at a site should have one record here.

## Main Device Fields

| Field | Required | Example | Notes |
|---|---|---|---|
| device_id | Yes | MTB-L1-MCP-001 | Internal unique ID. Can be generated by app. |
| device_tag | Yes | L1.MCP.1-Z?? | Site-visible tag. Use `Z??` until zone is confirmed. |
| client_name | Yes | MTB Reality Sdn Bhd | |
| site_name | Yes | MTB Reality Sdn Bhd | |
| building | No | Tower A | |
| floor_area | Yes | L1 | Basement / L1 / Roof / Pump Room etc. |
| location_description | Yes | Beside staircase | Human readable location. |
| device_type | Yes | MCP | Abbreviation such as MCP, SD, HR, EXT. |
| device_type_name | Yes | Manual Call Point | Full name. |
| system_type | Yes | Fire Alarm | Fire Alarm / Hose Reel / Sprinkler / Extinguisher etc. |
| active_or_passive | Yes | Passive | Active / Passive. Used for service scope rules. |
| zone | No | Z3 | Use `Z??` if unknown. |
| qr_barcode | No | UF032026Y967529 | Barcode/QR value if available. |
| serial_number | No | UF032026Y967529 | Pump/cylinder/extinguisher serial number. |
| brand | No | Notifier | |
| model | No | NFS2-3030 | |
| capacity_size | No | 9kg / 2kg / 150mm | For extinguisher, cylinder, tank, hood, pipe, etc. |
| year_of_manufacture | No | 2024 | |
| install_date | No | 2026-07-14 | |
| bomba_cert_expiry | No | 2027-07-08 | Especially extinguisher. |
| service_due_date | No | 2026-08-14 | |
| last_test_date | No | 2026-07-14 | |
| last_test_result | No | Pass | Pass / Fail / N/A. |
| condition_status | Yes | Active | Active / Missing / Defective / Replaced / Removed. |
| normal_photo_path | No | photos/device.jpg | Reference photo. |
| nameplate_photo_path | No | photos/nameplate.jpg | Important for pump/CO2/wet chemical/panel. |
| barcode_photo_path | No | photos/barcode.jpg | Important for extinguisher. |
| drawing_page | No | L1 | Draw.io/mimic page name. |
| drawio_x | No | 1234.50 | Marker x coordinate. |
| drawio_y | No | 678.90 | Marker y coordinate. |
| source | Yes | First-Time Setup | First-Time Setup / CAD / Hand Sketch / Manual / Import. |
