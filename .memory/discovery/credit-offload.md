## Practical Policy

- Use local tools for inventory and repeatable evidence.
- Use Ollama for classification only; its red-team pass produced factual errors and must not decide releases.
- Do not invoke Freebuff/Antigravity if their bridge requires an unapproved install or runtime mutation.
- Preserve Codex for implementation and cross-file/data-integrity decisions.
