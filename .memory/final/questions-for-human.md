# Questions For Human Review

## Production Hosting

**Question:** Managed backend or maintained Realmart server as the first production authority?  
**Why:** Determines auth, TLS, database, object storage, remote access and backup architecture.  
**Evidence:** Current local Node/JSON server is suitable only for supervised LAN pilot.  
**Default:** Prefer the lower-operations managed path unless Realmart appoints an IT owner.

## V1 Offline Boundary

**Question:** Is robust offline inspection required before the first Wetex pilot, or may the pilot remain online-first with local-draft blocking?  
**Why:** Production Dexie integration is high-risk and should not be rushed.  
**Default:** Physical POC now; integrate only if field connectivity makes it a pilot gate.

## SOP Approval

**Question:** Who signs off each site/system SOP version and N/A/evidence rule?  
**Why:** Software must not invent fire procedures.  
**Default:** Named Realmart technical approver plus site/customer version record.

## Evidence Retention

**Question:** Required photo/video retention period and whether GPS is required, optional or prohibited per customer?  
**Why:** Drives storage, privacy and report policy.  
**Default:** Photo timestamp/identity required; GPS configurable and consent-aware.

## Tablet Pilot

**Question:** Will technicians actually carry tablets at pilot sites?  
**Why:** Determines whether split-view and landscape work are V1 priorities.  
**Default:** Fix verified overflow now; defer a full tablet-specific layout until device use is confirmed.
